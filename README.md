# 💻 Portafolio de Emiliano

Portafolio personal desarrollado con **HTML, CSS y JavaScript**.  
La página presenta información personal, mis aficiones, estudios, trayectoria y objetivos profesionales dentro del mundo de la programación.

## 📖 Descripción

Este proyecto es una página web personal creada para presentarme y mostrar mi recorrido dentro del ámbito de la informática y el desarrollo web.

El portafolio está dividido en diferentes secciones:

- **Quién soy**
- **Mis aficiones**
- **Mis estudios**
- **Mi historia hasta aquí**
- **Mi visión de futuro**

También incluye enlaces a mis perfiles de **Twitch** y **GitHub**.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
